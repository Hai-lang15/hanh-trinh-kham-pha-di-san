# Hành Trình Khám Phá Di Sản - User UI

Đây là giao diện User bước đầu cho dự án.

## Cấu trúc

- index.html
- css/style.css
- js/app.js
- images/ (đặt ảnh di sản thật vào đây)

## Chạy

Có thể mở `index.html` bằng Live Server trong VS Code.

## Bước tiếp theo

1. Thay ảnh placeholder bằng ảnh thật của 4 địa điểm.
2. Tạo trang chi tiết từng di sản.
3. Kết nối Google Maps.
4. Làm đăng ký / đăng nhập / đăng xuất.
5. Kết nối Node.js + Express.
6. Kết nối Database.
7. Làm chức năng user đăng bài.
8. Làm admin duyệt bài.
9. Thêm Google OAuth.
